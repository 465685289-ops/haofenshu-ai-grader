AI 阅卷助手（好分数） v1.0 使用说明
=====================================

一、安装（Chrome / Edge 电脑版）
1. 解压本压缩包，得到 ai-grader 文件夹。
2. 浏览器地址栏打开 chrome://extensions （Edge 打开 edge://extensions）。
3. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选中 ai-grader 文件夹。
4. 把工具栏上的拼图图标里的「AI 阅卷助手」固定出来。

二、填 API Key
1. 点插件图标 →「模型与 API Key 设置」。
2. 选模型供应商（通义千问、豆包、智谱、Kimi、混元、文心、阶跃、硅基流动、OpenAI、Claude、Gemini、OpenRouter、本地 Ollama、自定义）。
3. 选模型（必须是能看图的视觉模型），填入 API Key → 点「测试连接（识图）」→ 成功后点「保存」。
   推荐：通义千问 qwen-vl-max、豆包 vision、智谱 glm-4.5v，手写中文识别较好，价格也低。
   注意：DeepSeek 官方接口不支持看图，不能用来批扫描答卷。

三、第一次在好分数上使用（每台电脑、每种题型设置一次）
1. 登录好分数，进入某道题的阅卷页面。面板会自动出现在右上角（没出现就点插件图标 →「在当前页面打开阅卷面板」）。
2. 「① 页面定位」
   · 选答题区：点按钮后，鼠标移到学生答题图片上点击。框太小就按键盘 ↑ 扩大到外层。
     如果点不中（画布显示），用「框选」直接拖一个矩形。
   · 选分数框：点分数输入框；如果是一排分值按钮，就选中整排按钮的外框。
   · 选提交按钮：点「提交」按钮（如果打分后会自动跳下一题，提交方式选「无需提交」）。
3. 「② 本题评分标准」：填满分、给分步长、参考答案、评分标准，越具体越准。
   点「保存为方案」，下次批同一题直接在下拉里选。
4. 先点「试批一题」看看 AI 给的分和理由（不会提交），满意再点「▶ 开始连续批改」。

四、连续批改
· 全自动模式：识别 → 给分 → 填分 → 提交 → 等下一题出现 → 继续。
· 每题确认模式：AI 给分后由你确认或改分，回车即提交。
· 当 AI 的把握低于设定值（默认 60%）时，即使全自动也会停下来让你确认。
· 连续 3 次出错、提交后没跳到新题、达到最多题数，都会自动停止。
· 快捷键：Alt+S 开始/暂停，Alt+X 停止。
· 「导出批改记录 CSV」可以保存本次每题的分数、理由和识别内容，方便复查。

五、隐私
API Key 只存在你自己的浏览器里；答卷图片从你的浏览器直接发给你选的模型供应商，不经过其他服务器。

六、建议
AI 给分仅作辅助。正式阅卷前请先用十几份答卷对比人工分数，调好评分标准；
作文等主观性强的题建议用「每题确认」模式。请遵守学校和考试的阅卷纪律。
